# 🚀 Algorithm Racing Platform 🏁
Mario Kart but for Algorithms!

Welcome to the Algorithm Racing Platform — a fun, interactive way to visualize, compare, and race popular algorithms across different categories! Select your racers, set up the track, and watch algorithms compete in real-time!

# 🎮 Features
✅ New Algorithm Categories Added:

## 🔧 Advanced Sorting Algorithms
Radix Sort 🔢 - Digit by digit champion

Counting Sort 🧮 - Number counting master

Shell Sort 🐚 - Gap jumping specialist

Bucket Sort 🪣 - Divide and conquer

## 🔍 Search Algorithms
Binary Search 🔍 - Divide and find (Super fast!)

Linear Search 🔦 - One by one explorer (The underdog)

Hash Search #️⃣ - Instant access wizard (Fastest!)

Interpolation Search 🎯 - Smart guesser

## 🗺️ Graph Algorithms
Dijkstra 🗺️ - Shortest path finder

A Search* 🧭 - Heuristic pathfinder

BFS 🌊 - Breadth-first explorer

DFS 🕳️ - Depth-first diver

## 🌳 Tree Algorithms
AVL Tree ⚖️ - Self-balancing master

Red-Black Tree 🔴 - Color-coded balancer

B-Tree 🌳 - Multi-way organizer

## 🧠 Dynamic Programming
Fibonacci DP 🧠 - Memory master

Knapsack DP 🎒 - Optimization expert

## 🔤 String Algorithms
KMP Search 🔤 - Pattern matching pro

Boyer-Moore ⏪ - Backward searcher

# ✨ New Platform Features
Category Filtering — Easily filter algorithms by type (Sorting, Search, Graph, etc.)

Smart Race Types — 8 dynamic race types auto-filter relevant algorithms

Increased Racer Limit — Up to 6 racers supported per race

Algorithm Badges — Each algorithm displays its category for easy identification

Auto-Filtering — Race type selection filters to show only relevant algorithms

# 📦 Getting Started
Clone the repository:
git clone <repository-link>
cd algorithm-racing-platform
Install dependencies: npm install
Run the app: npm start
Open http://localhost:3000 in your browser and start racing!
